# DollarFix: Effortless AI Solutions

Act as a Senior UI/UX Designer and React/Tailwind Developer. Build a modern, clean, and highly converting landing page for a micro-SaaS hub called "DollarFix". The domain is dollarfix.net. 

The website serves two purposes: an App Directory for 5 specialized AI tools, and a Unified Credit Store. 

Use a clean, modern aesthetic with soft shadows, plenty of whitespace, and smooth hover effects (similar to Stripe or Vercel). Use `lucide-react` for icons.

Here is the exact structure and content required:

1. Header:

- Logo text: "DollarFix" with a subtle icon.

- Right side: "Log in" (ghost button) and "Sign up" (primary solid button).

2. Hero Section:

- Headline (Large, bold, gradient text): "One problem, one dollar. Ping it!"

- Subheadline: "A suite of powerful, single-purpose AI tools. Buy credits once, use them universally across any app. No monthly subscriptions."

- CTA Button: "Explore Apps"

3. App Directory Section (Grid Layout):

- Section Title: "Our Specialized Tools"

- Create 5 modern cards, each with an icon, title, short description, and a "Launch App" button with a small arrow icon.

  - App 1: "PitchPing" | Icon: Briefcase | Desc: "Write winning, client-ready freelance pitches in seconds."

  - App 2: "CodePing" | Icon: Code | Desc: "Instant AI code review, debugging, and refactoring."

  - App 3: "ResumePing" | Icon: FileText | Desc: "Optimize your resume to beat ATS algorithms instantly."

  - App 4: "PDF SnapClarity" | Icon: FileSearch | Desc: "Extract insights and summarize complex PDFs instantly."

  - App 5: "BandPing" | Icon: GraduationCap | Desc: "Get accurate IELTS essay band scores and feedback."

4. Pricing & Credit Store Section:

- Section Title: "Universal Ping Credits"

- Add a transparent alert/info box at the top of this section: "Transparency Note: Using our tools without an account binds your credits to your current device. Creating a free account transforms your balance into Universal Cloud Credits, usable across all DollarFix apps!"

- Create a 3-column pricing grid:

  - Tier 1: 100 Credits | Price: $1 | Note: "Great for quick fixes"

  - Tier 2: 300 Credits | Price: $2 | Note: "Most Popular"

  - Tier 3: 500 Credits | Price: $3 | Note: "Best Value" (highlight this card slightly).

- Under the pricing grid, add a centered, stylized motivational quote: "Don't overthink it.. Fix it fast.. Just Ping it!"

5. Footer:

- Simple copyright: "© 2026 DollarFix. Made for problem solvers."

Technical Requirements:

- Ensure the layout is fully responsive (stacks on mobile, grid on desktop).

- Use distinct, professional colors (e.g., slate/gray background, primary vibrant accent color like Indigo or Emerald for CTAs).

- Write clean React code using standard Tailwind CSS classes.
